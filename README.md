# 진표의 영어 비행단 (v2 · 횡스크롤 비행)

왼쪽에서 오른쪽으로 날아가는 횡스크롤 비행 슈팅 게임으로 영어를 배웁니다.
**초1~초6** 난이도를 골라서 놀 수 있어요.

## 태블릿에 앱처럼 설치하기 (추천)
브라우저에서 주소를 연 다음:
- **아이패드(사파리)**: 공유 단추 → **홈 화면에 추가** → 나온 아이콘으로 실행 (주소창 없는 전체 화면)
- **안드로이드 태블릿(크롬)**: ⋮ → **앱 설치** 또는 **홈 화면에 추가**

한 번 실행해 두면 **인터넷이 없어도(비행기 모드에서도) 놀 수 있어요.** 놀 때는 화면이 저절로 꺼지지 않습니다.
가로로 들고 하는 게임이라 세로로 들면 "가로로 돌려 주세요" 안내가 떠요.

## 노는 법
- **↑ ↓ ← →** 비행 · **스페이스** 미사일 발사 · **R** 문제 다시 듣기 · **M** 지도로 · **P** 소리 끄기
- 화면 오른쪽 위의 🗺️ 🔊 단추로도 지도로 가거나 소리를 끌 수 있어요. 문제 띠를 누르면 다시 들려줘요.
- 폰·태블릿은 **한 손가락으로 화면을 끌어** 날고, **다른 손가락으로 화면을 톡 치거나** 오른쪽 아래 **🚀 발사** 버튼으로 쏴요
- **자유 비행 구간(약 9초)**: 문제 없이 새·바위·풍선·드론을 피하고 ⭐과 ❤️를 모아요
- **문제 구간**: **정답이 적힌 문 안으로 날아 들어가면** 통과예요 (쏘는 게 아니에요!)
  - ☁️ 세 개의 문 중 정답 문으로 들어가기 — 낱말·문장 빈칸·듣기·대화
  - 🔤 순서대로 문에 들어가기 — 철자 조립(c-a-t), 문장 어순 맞추기
  - 틀린 문에 들어가면 문이 닫히면서 비행기가 튕겨 나오고, 왜 틀렸는지 알려 줘요
- **미사일은 마음껏!** 미사일은 장애물과 ⭐별 풍선을 터뜨릴 때만 쓰여요. 아무리 쏴도 오답이 되지 않아요
- 문제 8개 + **보스전 3문제**로 한 하늘이 끝나요

## 교육 설계
- **간격 반복(Leitner)**: 낱말마다 숙련도 0~5를 저장해서 틀린 낱말은 곧 다시, 잘 아는 낱말은 한참 뒤에 나와요 (기기에 저장)
- **인출 연습**: 보기 고르기뿐 아니라 철자·어순을 직접 떠올려 만들어요
- **맥락 학습**: 익숙해진 낱말은 문장 속 빈칸으로 다시 만나요
- **반복 낭독**: 맞히면 영어 → 뜻 → 영어 → 뜻 → 영어 순으로 **세 번 반복**해 읽어 주고, 다 읽을 때까지 다음 구간으로 넘어가지 않아요
- **왜 틀렸는지 설명**: 틀리면 *내가 쏜 낱말의 뜻* → *정답과 그 뜻*을 말과 글로 알려 줘요 (예: "네가 쏜 건 egg, 달걀이라는 뜻이야. 정답은 water, 물")
- **소리를 게임에 담았어요**: 영어 1,600여 개 문구(낱말·문장·대화)와 한국어 안내를 **미리 녹음해서 넣었습니다**.
  기기에 영어 음성이 깔려 있든 없든, 태블릿이든 컴퓨터든 **똑같이 들립니다**. 게임 효과음과 같은 통로로 나오므로 게임 소리가 들리면 영어도 반드시 들려요.
- 처음 한 번은 인터넷으로 소리를 받아오고, 배경에서 조용히 전부 내려받아 두기 때문에 그 뒤에는 **인터넷 없이도** 들립니다.
- 녹음이 없는 문구만 기기 음성으로 읽어요. 지도의 `🔊 영어 소리 시험` 으로 확인할 수 있어요.
- **학습 리포트**: 한 판이 끝나면 오늘 익힌 낱말과 다시 볼 낱말을 보여 줘요
- **복습 비행**: 지도에서 📘 버튼으로 틀린 낱말만 모아 다시 날 수 있어요
