# 진표의 영어 비행단

미사일을 쏘고 폭탄을 피하면서 영어 낱말과 문장을 배우는 비행 슈팅 게임입니다.
**초1~초6** 난이도를 골라서 놀 수 있어요.

## 노는 법
- **← → ↑ ↓** 비행기 움직이기 · **스페이스** 미사일 발사
- 폰·태블릿은 **화면을 끌어서** 움직이고 오른쪽 아래 **🚀 발사** 버튼으로 쏴요
- 문제를 보고 **정답이 적힌 비행접시**를 맞히면 별 ★3, 한 번에 맞히면 하트도 하나 회복
- 틀리면 정답을 영어로 읽어 주고 같은 문제를 한 번 더 (하트 하나 잃어요)
- 떨어지는 폭탄에 맞으면 하트가 줄어요. 하트가 다 떨어지면 그 문제부터 다시 도전
- 문제 8개를 풀면 **보스 등장!** 보스는 문제 3개를 더 맞혀야 물리쳐요

## 학년별 하늘
| 하늘 | 배우는 것 |
|---|---|
| 초1 하늘 | 기초 낱말 (그림·소리로) |
| 초2 바다 | 낱말과 아주 짧은 문장 |
| 초3 구름 | 학교 낱말, 요일·시간 문장 |
| 초4 노을 | 장소·날씨 낱말, 짧은 대화 |
| 초5 우주 | 문장 빈칸, 과거형 |
| 초6 은하 | 긴 문장, 미래·비교, 대화 |

낱말 320개 · 문장 90개 · 대화 25개가 들어 있고, 문제는 놀 때마다 새로 만들어집니다.

## 영어 읽어주기 🔊
- 듣기 문제는 영어 낱말·문장을 천천히 읽어 줘요
- **답을 맞히거나 틀린 뒤에는 꼭** 영어를 두 번 읽고 한글 뜻까지 알려 줘요
- 문제 띠의 🔊 단추를 누르면 다시 들을 수 있어요
